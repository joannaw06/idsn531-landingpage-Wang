## 🚀 Project Description

This is a multi-page personal portfolio website built as the final project for IDSN 531. The site features a homepage, a project gallery, a detailed case study for the "AirNest" startup, and a functional contact page. The entire site is fully responsive and designed with a clean, dark-mode aesthetic.

---

## 🛠️ Features & Rubric Breakdown

This project meets the course requirements in the following ways:

### 1. Creativity
* **Concept:** The site serves as a professional portfolio, blending a minimalist dark-mode homepage with a vibrant, full-page case study for the "AirNest" project.
* **Originality:** It features a unique "scrolly-telling" `start-up.html` page that transitions from a green, branded hero section into a clean, white-BG "deliverable" section at the bottom.

### 2. Use of Transitions
* **Homepage:** Interactive hover effects (`text-shadow`) on the intro text and "pop-out" cards for the main content.
* **Projects Page:** A custom jQuery-powered image slider for each project gallery, allowing users to click through multiple images.
* **Global:** A fully-functional hamburger menu that smoothly toggles the navigation on mobile.

### 3. Styling
* **CSS:** The site is styled with a single, well-organized `style.css` file that uses `body` classes (e.g., `.home-page`, `.startup-page`) to manage different themes for each page.
* **Layout:** The site is built with modern CSS (Flexbox and Grid) to create responsive 2-column and 3-column layouts.
* **Visual Coherence:** The design is unified by a consistent dark theme, a green accent color, and a shared typography pairing (`Inter` for body text and `DM Serif Text` for headings).

### 4. Accessibility
* **Semantic HTML:** Uses semantic tags like `<nav>`, `<main>`, `<section>`, and `<footer>` to give the page proper structure.
* **Alt Text:** All images (e.g., `<img src="..." alt="Description of image">`) include descriptive alt text for screen readers.
* **Keyboard Navigation:** The site is navigable using the "Tab" key, with clear focus states on links and buttons.
* **Contrast:** All text meets high-contrast standards for readability (e.g., white text on dark backgrounds, green text on white backgrounds).
